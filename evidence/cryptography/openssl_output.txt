=== 1. SHA-256 with openssl dgst ===
$ openssl dgst -sha256 data/synthetic/campus_records.csv
SHA2-256(data/synthetic/campus_records.csv)= 31b32db9b45b593f19a7c4088b393e76f35a51641fb156024751b1a3db28c4ac

=== 2. Encrypt: AES-256-CBC, key derived from passphrase with PBKDF2 (100000 iterations, random salt) ===
$ openssl enc -aes-256-cbc -pbkdf2 -iter 100000 -salt -in campus_records.csv -out records.ossl.enc -pass env:CS_LAB_PASS
2528 bytes  demonstrations/cryptography/output/records.ossl.enc
first 32 bytes of the encrypted file (starts with 'Salted__' + 8-byte salt):

=== 3. Decrypt and compare ===
$ openssl enc -d -aes-256-cbc -pbkdf2 -iter 100000 -in records.ossl.enc -out ossl_decrypted.csv -pass env:CS_LAB_PASS
cmp: decrypted file is IDENTICAL to the original
