
### 6. Remove unnecessary service, run secure build as cs_app, host firewall
Initial firewall state:

$ iptables -S
-P INPUT ACCEPT
-P FORWARD ACCEPT
-P OUTPUT ACCEPT
Backup share on :8000 is NOT restarted (unnecessary service removed).

$ ss -ltnp | grep -E ':(5000|8000) '
LISTEN 0      128          0.0.0.0:5000       0.0.0.0:*   

$ ps -o user,pid,cmd -C python3 | grep run_app
cs_app     432 python3 /opt/campushield/scripts/run_app.py --mode secure --host 0.0.0.0 --port 5000 --allow-lab-exposure

Firewall rules applied (only the lab veth interfaces are affected):

$ iptables -S CS_LAB_IN
-N CS_LAB_IN
-A CS_LAB_IN -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
-A CS_LAB_IN -s 10.10.60.0/24 -p tcp -m tcp --dport 5000 -m conntrack --ctstate NEW -j ACCEPT
-A CS_LAB_IN -m limit --limit 20/min -j LOG --log-prefix "CS-FW-DROP "
-A CS_LAB_IN -j DROP

$ iptables -S INPUT | head -5
-P INPUT ACCEPT
-A INPUT -i cs-staff-h -j CS_LAB_IN
-A INPUT -i cs-untr-h -j CS_LAB_IN

Connectivity checks:

$ ip netns exec cs_staff curl -s -m 5 -o /dev/null -w 'staff zone   -> :5000  HTTP %{http_code}\n' http://10.10.60.1:5000/login
staff zone   -> :5000  HTTP 200

$ ip netns exec cs_untrusted curl -s -m 5 -o /dev/null -w 'untrusted    -> :5000  HTTP %{http_code}\n' http://10.10.50.1:5000/login || echo '=> untrusted zone BLOCKED (timeout)'
untrusted    -> :5000  HTTP 000
=> untrusted zone BLOCKED (timeout)

$ ip netns exec cs_staff nc -zv -w 3 10.10.60.1 8000 || echo '=> :8000 closed/blocked'
nc: connect to 10.10.60.1 port 8000 (tcp) timed out: Operation now in progress
=> :8000 closed/blocked

$ ip netns exec cs_staff nc -zv -w 3 10.10.60.1 22 || echo '=> other ports from staff zone blocked'
nc: connect to 10.10.60.1 port 22 (tcp) timed out: Operation now in progress
=> other ports from staff zone blocked
